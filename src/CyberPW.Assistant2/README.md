# CyberPW Assistant 2.0 (BETA)

Нативна WinForms-версія на C# для .NET Framework 4.8.

## Навіщо переписали

- швидший запуск без PowerShell і чорного консольного вікна;
- миттєве перемикання між модулями в одному процесі;
- швидкий системний ввід клавіатури та миші через Windows `SendInput`;
- спільне DPI-масштабування, дизайн і обробка помилок;
- portable-запуск без Python, npm і сторонніх бібліотек.

## Статус

Версія 2.0 перебуває у статусі **Beta**. Вона може працювати не на всіх ПК через відмінності Windows, DPI, .NET Framework, прав доступу, антивірусів і версій `ElementClient.exe`.

Основна стабільна гілка не змінюється; 2.0 розробляється й публікується окремо.
