# CyberPW Assistant 2.0.13 Beta — HOTFIX

Це hotfix для TitulHelper. **Алгоритм автоматичного введення координат і назви титулу змінено** для стабільнішої роботи з ElementClient.

## Що виправлено

- Перед автоматичним введенням TitulHelper активує вікно CyberPW та двічі натискає `Esc`, щоб закрити відкриті панелі й діалоги, які могли перехопити введення.
- Після успішного введення титулу виконується `Esc ×3`, щоб очистити інтерфейс перед наступною операцією.
- КРОК 1 — кнопка зі стрілочкою біля карти — тепер перевіряється: програма контролює, чи поле координат справді відкрилося.
- Якщо перший клік по стрілочці загубився через фокус або затримку клієнта, виконується одна контрольована повторна спроба.
- Якщо поле координат так і не відкрилося, автовведення зупиняється. Координати та назва не вводяться у випадкове активне поле.
- Для визначення відкритого поля використовується 7 контрольних точок навколо поля координат замість одного пікселя.
- Введення переведено зі `SendKeys` на WinAPI/`MacroNative` для стабільнішої роботи з вікном гри.
- Посилено повторне повернення фокусу в `ElementClient` перед кліками та завершальним очищенням інтерфейсу.

> Після оновлення рекомендується один раз заново пройти **TitulHelper → НАЛАШТУВАТИ КООРДИНАТИ → КРОК 1 / КРОК 2**, щоб зберегти нову контрольну сигнатуру поля координат.
