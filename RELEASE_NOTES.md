# CyberPW Assistant 2.0.18 Beta — OCR download fix

Це виправлення `2.0.17-beta` для модуля **«Автовідповіді · SUPER BETA»**.

## Виправлено

- Прибрано залежність від прямого Mannheim URL, який на частині ПК повертав **403 Forbidden**.
- Інсталятор Tesseract 5.4 тепер завантажується з офіційного GitHub Release UB-Mannheim.
- Українська та російська OCR-моделі як і раніше завантажуються з `tessdata_fast`.
- Сам модуль Чон-Пон + КХ, кастомна область, AUTO 1.5 с, top-3 збігів і safe-confidence залишаються без змін.

Оновлення встановлюється штатно через кнопку **«ОНОВЛЕННЯ»** з `2.0.17-beta`.
