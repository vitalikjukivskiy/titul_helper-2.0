# CyberPW Assistant 2.0.15 Beta — AutoUpdate Release

Це технічне оновлення для переходу на нормальний сценарій: **оновлення тільки через кнопку «ОНОВЛЕННЯ» у CyberPW Assistant**, без ручного скачування нових дистрибутивів для кожного патчу.

## Що зроблено

- Версію піднято до `2.0.15-beta` та синхронізовано з `AssemblyVersion` / `FileVersion`.
- Збережено перевірений GitHub Releases канал автооновлення через `CyberPW Updater.exe`.
- Збережено SHA-256 перевірку архіву перед встановленням.
- Збережено fail-safe перевірки TitulHelper перед автоматичним введенням координат і назви.
- Збережено локальні дані користувача під час оновлення: прогрес титулів, профілі та макроси.
- Release workflow збирає один updater-сумісний `CyberPW-Assistant-2.0-Beta-Portable.zip` і публікує його в GitHub prerelease.
- Прибрано випадковий службовий порожній файл із кореня репозиторію.

## Як оновлюватися далі

Відкрий CyberPW Assistant і натисни **«ОНОВЛЕННЯ»**. Assistant сам перевірить GitHub, покаже опис нової версії, завантажить ZIP, перевірить SHA-256 і передасть встановлення `CyberPW Updater.exe`.

Функціональна логіка модулів у цьому maintenance-релізі не змінюється — мета версії `2.0.15-beta` полягає у чистому та перевіреному циклі автооновлення.
