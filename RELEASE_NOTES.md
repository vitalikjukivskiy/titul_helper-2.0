# CyberPW Assistant 2.0.16 Beta — Автовідповіді SUPER BETA

Це функціональне оновлення, яке реально додає новий модуль у ліве меню CyberPW Assistant.

## Новий модуль

- Додано вкладку **«АВТОВІДПОВІДІ · SUPER BETA»** у ліве меню.
- Модуль працює з базами **КХ (79 питань)** і **Чон-Пон (200 питань)**, які вже вбудовані в Assistant.
- OCR читає питання з вікна CyberPW і показує відповідь тільки коли збіг достатньо впевнений.
- Додано блок **«НАЙКРАЩІ ЗБІГИ»** з топ-3 кандидатами.
- Автокліків немає: модуль тільки сканує і показує відповідь.

## OCR і область сканування

- Додано кнопку **«ПІДГОТУВАТИ OCR»**: Tesseract OCR встановлюється локально в папку даних CyberPW Assistant.
- Українська та російська мовні моделі завантажуються автоматично.
- Додано **«НАЛАШТУВАТИ ОБЛАСТЬ»** — користувач мишкою виділяє прямокутник вікторини.
- Додано **«АВТО-ОБЛАСТЬ»** для повернення стандартної області.
- Додано режим **«АВТО 1.5 с»** для повторного сканування без автокліку.

## Оновлення

Версія доставляється через той самий перевірений механізм GitHub Releases. Відкрий CyberPW Assistant `2.0.15-beta` і натисни **«ОНОВЛЕННЯ»** — Assistant сам завантажить `2.0.16-beta`, перевірить архів і встановить його через `CyberPW Updater.exe`.
