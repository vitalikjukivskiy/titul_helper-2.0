# CyberPW Assistant 2.0.14 Beta — Maintenance / Audit Fix

Це технічне оновлення після повної перевірки репозиторію, збірки та механізму автооновлення.

## Що виправлено

- Версія в лівому меню більше не зашита вручну: Assistant читає її з файла `VERSION`, тому номер у програмі не буде відставати від релізу.
- `AssemblyVersion` і `FileVersion` синхронізовано з `2.0.14-beta`.
- CI та release workflow продовжують перевіряти, що версія зібраного EXE збігається з `VERSION`.
- Виправлено посилання README на актуальні prerelease-релізи.
- Оновлено portable-документацію: додано актуальні модулі, обидві вікторини та опис нового fail-safe алгоритму TitulHelper.

## Перевірено перед релізом

- TitulHelper: `Esc ×2` перед введенням, `Esc ×3` після введення, контроль КРОКУ 1, повторна спроба відкриття поля координат і fail-safe.
- Вікторина КХ — 79 записів.
- Вікторина Чон-Пон — 200 записів.
- Збірка `CyberPW Assistant 2 Beta.exe` і `CyberPW Updater.exe`.
- Формування updater-сумісного `CyberPW-Assistant-2.0-Beta-Portable.zip`.
- Збереження локальних даних користувача під час оновлення.

Функціональна логіка вікторин, TitulHelper і автооновлення не змінювалася — це maintenance-реліз для синхронізації версій, документації та результатів повного аудиту.
