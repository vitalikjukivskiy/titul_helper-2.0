# CyberPW Assistant 2.0.19 Beta — SWAP PROBE SUPER BETA

Перший read-only етап майбутнього швидкого П.А / П.З swap.

## Новий модуль SWAP PROBE

- Додано окрему вкладку **«SWAP PROBE · SUPER BETA»**.
- Працює тільки на читання: `OpenProcess + ReadProcessMemory + VirtualQueryEx`.
- `WriteProcessMemory` у модулі відсутній.
- Можна зробити **Snapshot A**, перемістити одну річ у CyberPW, зробити **Snapshot B** і порівняти зміни.
- Показується топ кандидатів: адреса, INT32 до/після, delta та base region.
- Результат можна зберегти у CSV у `data/swap-probe`.

## Як тестувати

1. Відкрий інвентар і не роби зайвих дій.
2. Натисни `SNAPSHOT A`.
3. Перетягни одну конкретну шмотку між двома комірками або один раз одягни/зніми її.
4. Натисни `SNAPSHOT B`.
5. Натисни `ПОРІВНЯТИ` і `ЗБЕРЕГТИ CSV`.

Цей реліз ще **не свапає екіпіровку**. Він потрібен, щоб знайти стабільну структуру `inventory slot / itemId / instanceId`, після чого буде додано реальний менеджер П.А / П.З сетів.

Оновлення встановлюється штатно через кнопку **«ОНОВЛЕННЯ»**.
