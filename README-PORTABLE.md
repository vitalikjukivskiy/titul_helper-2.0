# CyberPW Assistant 1.06 Beta

## Запуск

1. Повністю розпакуйте portable-архів.
2. Запустіть `Запустити.bat`.
3. Не запускайте програму прямо з ZIP: налаштування мають записуватися у папку програми.

## TitulHelper

Запустіть гру, увійдіть на персонажа й натисніть **СИНХРОНІЗУВАТИ**. Отримані титули позначаться без OCR. Невідома версія клієнта буде безпечно відхилена. Виберіть титул і скористайтеся кнопкою введення координат для створення мітки.

## Модулі

- TitulHelper;
- MultiLauncher;
- Macro Studio (клікер, **Beta**);
- карта територіальних війн (ГВГ, **Beta**);
- симулятор Скрині Тора;
- розморозка вікон;
- світові та хроно-боси;
- календар івентів.

## Macro Studio — Beta

Макрос створюється графічно: клавіші, миша, паузи, текст, цикли й очікування кольору пікселя. У полях `СТАРТ` і `СТОП` задайте власні кнопки для кожного макросу, наприклад `F10` та `F12`. Обидві клавіші зберігаються разом зі сценарієм.

## ГВГ — Beta

Карта та локальне редагування територій працюють у тестовому режимі. Автоматичної синхронізації власників і боїв із сервером поки немає.

## Windows 7

Потрібні Windows 7 SP1 x64, .NET Framework 4.8 та Windows Management Framework 5.1.

## Локальні дані

`state.json`, `characters.json`, `territories.json`, `launcher-theme.json` і папка `macros/` належать користувачу. Не публікуйте їх без перевірки.
