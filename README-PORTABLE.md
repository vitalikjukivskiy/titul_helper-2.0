# CyberPW Assistant 2.0 Beta

> **Увага:** це Beta-версія. Через відмінності Windows, DPI, прав доступу й версій клієнта окремі функції можуть працювати не на всіх ПК.

## Запуск

1. Повністю розпакуйте portable-архів.
2. Двічі натисніть `CyberPW Assistant 2 Beta.exe` — жодного чорного вікна PowerShell.
3. Не запускайте програму прямо з ZIP: налаштування мають записуватися у папку програми.

Версія 2.0 працює через C# EXE без окремого вікна PowerShell.

## TitulHelper

Натисніть **⚙ НАЛАШТУВАТИ КООРДИНАТИ** і пройдіть обидва кроки прив’язки. Поточний алгоритм перед введенням очищає відкриті панелі через `Esc`, перевіряє відкриття поля координат біля карти, за потреби робить одну повторну спробу й зупиняється, якщо поле не відкрилося.

Запустіть гру, увійдіть на персонажа й натисніть **СИНХРОНІЗУВАТИ З КЛІЄНТОМ**. Отримані титули позначаться без OCR. Якщо відкрито кілька клієнтів, TitulHelper запропонує вибрати потрібний `ElementClient`.

## Вікторини

Обидві вікторини працюють локально та офлайн. Доступні пошук за питанням або відповіддю та фільтри за рівнями.

## Macro Studio — Beta

Макрос створюється графічно: клавіші, миша, паузи, текст, цикли й очікування кольору пікселя. У полях `СТАРТ` і `СТОП` задайте власні кнопки для кожного макросу. Локальні макроси зберігаються в папці `macros/`.

## Автоматичні оновлення — Beta

Assistant перевіряє нові версії на GitHub під час запуску. Також перевірку можна запустити кнопкою **ОНОВЛЕННЯ** у верхній панелі. Перед встановленням програма покаже версію та опис змін. Архів перевіряється за SHA-256, а `CyberPW Updater.exe` зберігає локальний прогрес, профілі й макроси.

## Локальні дані

`data/state.json`, `characters.json`, `territories.json`, `launcher-theme.json` і папка `macros/` належать користувачу. Не публікуйте їх без перевірки.
