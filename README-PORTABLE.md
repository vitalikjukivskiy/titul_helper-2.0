# CyberPW Assistant 0.90 Design Preview

## Запуск

1. Повністю розпакуйте portable-архів.
2. Запустіть `Запустити.bat`.
3. Не запускайте скрипти прямо з ZIP — локальні налаштування та макроси мають записуватися у папку програми.

## Модулі

- TitulHelper;
- MultiLauncher;
- Macro Studio (клікер, Beta);
- карта територіальних війн (ГВГ, Beta);
- симулятор Скрині Тора;
- розморозка вікон;
- світові та хроно-боси;
- календар івентів.

## Macro Studio (клікер) — Beta

Макрос створюється графічно: клавіші, миша, паузи, текст, цикли та очікування кольору пікселя. У полі `КЛАВІША` введіть кнопку запуску поточного макросу, наприклад `F10`, `F6`, `G` або `5`; стандартно встановлено `F10`. `F12` аварійно зупиняє сценарій і відпускає затиснуті клавіші.

Це тестовий модуль. Перед використанням у грі перевірте сценарій у безпечному вікні.

## Карта територіальних війн (ГВГ) — Beta

Карта та локальне редагування територій працюють у тестовому режимі. Автоматичної синхронізації власників і боїв із сервером поки немає.

> Використовуйте автоматизацію лише відповідно до правил сервера. У програмі немає прихованого драйвера чи обходу античита.

## Windows 7

Потрібні Windows 7 SP1, .NET Framework 4.8 та Windows Management Framework 5.1. Усі модулі, крім системного Windows OCR, залишаються доступними.

## Дані користувача

У папці програми можуть створюватися:

- `state.json` — прогрес титулів;
- `characters.json` — профілі MultiLauncher;
- `territories.json` — стан карти ТВ;
- `launcher-theme.json` — тема;
- `macros/` — власні макроси;
- `scan-report.json` і `scan-pages/` — OCR-звіти.

Не публікуйте ці файли, якщо вони містять персональні налаштування.
