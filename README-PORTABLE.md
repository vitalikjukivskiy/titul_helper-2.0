# Cyber.pw Asistant — TitulHelper

Portable-помічник для гравців CyberPW: сканує список отриманих титулів, позначає їх у програмі та автоматично встановлює мітки з координатами у грі.

## Запуск

1. Повністю розпакуйте ZIP-архів у звичайну папку.
2. Запустіть `Запустити.bat`.
3. Відкрийте CyberPW у віконному режимі та виконайте калібрування за підказками TitulHelper.
4. Якщо сканування повідомляє про відсутність OCR, запустіть `Встановити OCR.bat` і підтвердьте права адміністратора.

Підтримуються Windows 10/11. Python, сторонні бібліотеки та окрема інсталяція програми не потрібні.

Програма працює через звичайні кліки, клавіатуру та знімки області екрана. Вона не втручається у пам'ять клієнта гри.
