# CyberPW Assistant 2.0 Beta

> **Увага:** це Beta-версія. Через відмінності Windows, DPI, прав доступу й версій клієнта окремі функції можуть працювати не на всіх ПК.

## Запуск

1. Повністю розпакуйте portable-архів.
2. Двічі натисніть `CyberPW Assistant 2 Beta.exe` — жодного чорного вікна PowerShell.

Версія 2.0 повністю працює через нативний C# EXE без вікна PowerShell.
3. Не запускайте програму прямо з ZIP: налаштування мають записуватися у папку програми.

## TitulHelper

Натисніть **⚙ НАЛАШТУВАТИ КООРДИНАТИ** — відкриється майстер із двома скріншотами потрібних елементів гри та окремими кроками прив’язки.

Запустіть гру, увійдіть на персонажа й натисніть **СИНХРОНІЗУВАТИ**. Отримані титули позначаться без OCR. Невідома версія клієнта буде безпечно відхилена. Якщо відкрито кілька клієнтів, TitulHelper покаже список вікон і попросить вибрати потрібного персонажа; є кнопка **ПОКАЗАТИ ВІКНО**. Виберіть титул і скористайтеся кнопкою введення координат для створення мітки.

## Модулі

- TitulHelper;
- MultiLauncher;
- Macro Studio (клікер, **Beta**);
- карта територіальних війн (ГВГ, **Beta**);
- симулятор Скрині Тора;
- розморозка вікон;
- світові та хроно-боси;
- календар івентів.

## Macro Studio — Beta

Макрос створюється графічно: клавіші, миша, паузи, текст, цикли й очікування кольору пікселя. У полях `СТАРТ` і `СТОП` задайте власні кнопки для кожного макросу, наприклад `F10` та `F12`. Обидві клавіші зберігаються разом зі сценарієм. Для кольору доступні **ЧЕКАТИ КОЛІР**, **IF КОЛІР**, **IF NOT КОЛІР** і вкладені умовні блоки.

## Windows 7

Потрібні Windows 7 SP1 x64, .NET Framework 4.8 та Windows Management Framework 5.1.

## Локальні дані

`state.json`, `characters.json`, `territories.json`, `launcher-theme.json` і папка `macros/` належать користувачу. Не публікуйте їх без перевірки.
