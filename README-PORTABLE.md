# Cyber.pw Asistant 0.82 Beta

Portable-помічник для гравців CyberPW: сканує список отриманих титулів, позначає їх у програмі та автоматично встановлює мітки з координатами у грі.

Вкладка **MultiLauncher** дозволяє створити профіль персонажа без ручного редагування файлів: вказати нік, вибрати клас, ввести логін і пароль, а потім запускати одного, вибраних або всіх персонажів із безпечною затримкою між вікнами. Сканування старих BAT-файлів не потрібне. Для версії 1.4.6 доступні 10 класів із власними нефритово-золотими ілюстраціями: Воїн, Маг, Танк, Друїд, Лучник, Жрець, Асасин, Шаман, Страж і Містик.

Кнопка **Акаунт** дозволяє змінити логін і пароль профілю. За бажанням вони запам’ятовуються у `characters.json` у зашифрованому Windows вигляді та можуть бути розшифровані лише тим самим користувачем Windows на тому самому комп’ютері. Для кожного профілю автоматично створюється BAT-ярлик у папці `profiles`; він містить лише ідентифікатор профілю, без логіна та пароля.

Вкладка **Симулятор скрині (BETA)** відтворює відкриття Скрині Тора за шансами зі скріншота, веде накопичувальну статистику й показує фактичну частоту випадінь. Сума наданих шансів дорівнює 100,137%, тому ваги пропорційно нормалізуються. Усі іконки предметів — оригінальні PNG-ресурси Perfect World, отримані зі сторінки прикладу; зображення не генерувалися.

Вкладка **Розморозка вікон** показує всі запущені клієнти `ElementClient`. Позначте потрібні вікна галочками — команда `d_rendernofocus 1` буде виконана лише для них.

Вкладка **Світові боси** містить українські назви та координати 16 світових і 8 хроно-босів, розклад появи й таблицю дропу. Вона дозволяє вибрати конкретне вікно гри та встановити мітку, використовуючи калібрування TitulHelper.

## Запуск

1. Повністю розпакуйте ZIP-архів у звичайну папку.
2. Запустіть `Запустити.bat`.
3. Відкрийте CyberPW у віконному режимі та виконайте калібрування за підказками TitulHelper.
4. Якщо сканування повідомляє про відсутність OCR, запустіть `Встановити OCR.bat` і підтвердьте права адміністратора.

Підтримуються Windows 7 SP1, Windows 10 і Windows 11. Для Windows 7 потрібні .NET Framework 4.8 та Windows Management Framework 5.1. Автоматичний OCR-скан у Windows 7 недоступний, але пошук, ручні позначки, встановлення міток та інші модулі працюють.

Програма працює через звичайні кліки, клавіатуру та знімки області екрана. Вона не втручається у пам'ять клієнта гри.
