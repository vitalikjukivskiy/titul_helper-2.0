# CyberPW Assistant 0.90 Design Preview — новий гайд

> Готовий текст для нової теми на форумі. Стару тему [TitulHelper 0.82](https://forum.cyberpw.fun/index.php?threads/titulhelper.266/) можна залишити як архів.

## Що це таке

**CyberPW Assistant** — безкоштовний portable-набір інструментів для гравців CyberPW. Програма об’єднує TitulHelper, MultiLauncher, Macro Studio, карту територіальних війн, босів, календар івентів та інші корисні модулі в одному лаунчері.

- **Актуальна версія:** 0.90 Design Preview
- **Системи:** Windows 7 SP1, Windows 10, Windows 11
- **Формат:** portable, без інсталятора
- **Вихідний код:** [GitHub](https://github.com/vitalikjukivskiy/titul_helper)
- **Завантаження:** [Releases](https://github.com/vitalikjukivskiy/titul_helper/releases/tag/v0.90-design-preview)

> [!IMPORTANT]
> Macro Studio (клікер) і розділ ГВГ перебувають у статусі **Beta**. Перед використанням автоматизації перевірте правила сервера та протестуйте сценарій у безпечному вікні.

## Основні можливості

### TitulHelper

- 259 точок запуску титулів у 37 ланцюжках;
- пошук, прогрес і ручні позначки;
- автоматичне введення координат і створення мітки;
- калібрування під власну роздільну здатність;
- OCR-сканування вже отриманих титулів;
- підтримка кількох моніторів.

### MultiLauncher

- профілі персонажів і вибір класу;
- запуск одного, вибраних або всіх клієнтів;
- регульована затримка між запусками;
- паролі шифруються Windows для поточного користувача;
- BAT-ярлики не містять логінів і паролів.

### Macro Studio (клікер) — Beta

Візуальний редактор дозволяє складати макрос без написання коду:

- натискання та затискання клавіш;
- ліва, права і середня кнопки миші;
- переміщення курсора;
- паузи, текст і цикли;
- очікування заданого кольору пікселя;
- проста кнопка **ЗАПУСТИТИ**;
- поле **КЛАВІША**, де можна ввести `F10`, `F6`, `G`, `5` тощо;
- `F12` — аварійна зупинка з відпусканням затиснутих клавіш.

Клавіша запуску зберігається окремо в JSON кожного макросу.

### Карта територіальних війн (ГВГ) — Beta

- 51 інтерактивна територія;
- точні полігони на карті;
- власник, атакуючий і захисний клани;
- час бою, рівень, нагорода та нотатки;
- локальне збереження даних.

Автоматичної синхронізації власників і боїв із сервером поки немає.

### Інші модулі

- 16 світових і 8 хроно-босів із координатами та розкладом;
- календар серверних івентів;
- розморозка вибраних вікон ElementClient;
- симулятор Скрині Тора зі статистикою випадінь;
- світла й темна теми;
- оновлений округлений дизайн усіх основних вікон.

## Встановлення

1. Відкрийте [сторінку релізу 0.90](https://github.com/vitalikjukivskiy/titul_helper/releases/tag/v0.90-design-preview).
2. Завантажте `Cyber.pw-Asistant-Portable.zip`.
3. Повністю розпакуйте ZIP у звичайну папку.
4. Запустіть `Запустити.bat`.
5. Для OCR за потреби запустіть `Встановити OCR.bat` від адміністратора.

Не запускайте програму безпосередньо з ZIP. Python, npm та сторонні бібліотеки не потрібні.

## Перше налаштування TitulHelper

1. Запустіть CyberPW у віконному або безрамковому режимі.
2. Відкрийте TitulHelper і перейдіть у налаштування.
3. Послідовно вкажіть кнопку карти, поле координат, поле назви мітки та кнопку створення мітки.
4. Натисніть **Зберегти**.

Повторне калібрування потрібне після зміни роздільної здатності, масштабу Windows або інтерфейсу гри.

## Сумісність

- **Windows 11:** повна підтримка;
- **Windows 10:** повна підтримка;
- **Windows 7 SP1:** потрібні .NET Framework 4.8 і Windows Management Framework 5.1; системний Windows OCR недоступний.

## Безпека

CyberPW Assistant не читає пам’ять гри, не змінює файли клієнта й не містить прихованого драйвера або обходу античита. Локальні профілі, макроси та налаштування не публікуються в GitHub.
