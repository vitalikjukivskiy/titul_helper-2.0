# Changelog

## 0.82 Beta — 2026-07-24

- Додано світлу й темну теми до лаунчера та всіх окремих модулів.
- Додано перемикач теми зі збереженням вибору користувача.
- Додано компактний календар і розклад івентів на головну сторінку.
- Виправлено лічильник TitulHelper: тепер коректно відображається `0 / 259` замість `0 / 1`.
- Покращено адаптивне масштабування та зміну розміру всіх вікон.
- Додано сумісний режим для Windows 7 SP1 із перевіркою PowerShell 5.1.
- На Windows 7 автоматично вимикається недоступний системний OCR без впливу на ручні функції TitulHelper.
- Додано зрозуміле повідомлення замість помилки під час запуску інсталятора OCR у Windows 7.
- Додано окрему вкладку «Розморозка вікон».
- Додано вибір клієнтів `ElementClient` галочками та виконання `d_rendernofocus 1` лише для вибраних вікон.
- MultiLauncher тепер запускає гру з параметром `console:1`.
- Виправлено 64-бітну структуру WinAPI `SendInput`, через яку debug-консоль відкривалась, але команда не вводилася.
- Додано вкладку «Світові боси» з вибором конкретного вікна гри.
- Додано українську базу з 16 світових і 8 хроно-босів.
- Додано координати босів, розклад хроно-подій і таблицю шансів випадіння.
- Додано автоматичне встановлення міток босів через калібрування TitulHelper.
- Оновлено головну навігацію, portable-збірку та документацію.

- Виправлено падіння симулятора під час створення `ImageList`.
- Оновлено portable-збірку та документацію.
