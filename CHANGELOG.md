# Changelog

## 1.07 Beta 2 — 2026-07-29

- Додано основний `CyberPW Assistant.exe`: запуск подвійним кліком без консолі PowerShell.
- У EXE вбудовано багаторозмірний логотип CyberPW для Провідника Windows.
- Усі модулі переведено на безконсольний запуск через єдиний EXE.
- `Запустити.vbs` і `Запустити.bat` залишено як резервні способи.
- Основний реліз `v1.0.0` не змінюється; Beta 2 публікується окремо.

## 1.07 Beta — 2026-07-29

### Просте налаштування TitulHelper

- Дві технічні кнопки прив’язки координат замінено однією кнопкою **НАЛАШТУВАТИ КООРДИНАТИ**.
- Додано покроковий майстер із реальними скріншотами кнопки відкриття панелі та поля координат.
- Майстер показує стан кожного кроку й працює повністю локально без інтернету.

### Macro Studio Beta

- Виправлено захоплення пікселя: Macro Studio ховається перед відліком і більше не зчитує власне вікно.
- Додано `IF КОЛІР`, `IF NOT КОЛІР` і `КІНЕЦЬ IF`.
- Підтримуються вкладені умови та умови всередині циклів `REPEAT`.
- Компілятор перевіряє неправильну вкладеність і незакриті блоки до запуску макросу.
- Автотести підтвердили читання реального пікселя, переходи вкладених IF та IF усередині REPEAT.
## 1.06 Beta — 2026-07-29

### Профілі адрес і offsets

- Жорстко задані адреси TitulHelper винесено в окремий `memory-offsets.json`.
- Читання побудовано за схемою `base address → root offset → pointer chain → структура титулів`.
- Профіль прив’язаний до розміру й SHA256 конкретного `ElementClient.exe`.
- Після оновлення клієнта можна додати новий профіль offsets без переписування модуля синхронізації.
- Живий тест: два послідовні читання дали однакові 270 унікальних ID без розбіжностей.
- Додано безпечний вибір конкретного вікна/PID при одночасному запуску кількох клієнтів; один клієнт вибирається автоматично.
- Діалог дозволяє показати вибране вікно перед синхронізацією.
## 1.05 Beta — 2026-07-28

### Виправлення TitulHelper

- Виправлено синхронізацію після входу іншим або новим персонажем, який має лише один відомий титул.
- Усунено помилку: `Перевірка структури не пройдена: лише 0 із 1 ID відомі програмі. Прогрес не змінено.`
- Додано системний титул `Новачок` (`clientTitleId: 9999`); у базі тепер 260 титулів, із них 259 мають координатні точки.
- Системні титули без координат більше не дозволяють помилково ставити мітку `0 0`.

### Macro Studio Beta

- Прискорено клавіатуру, текст і мишу через Windows `SendInput`.
- Для кожного макросу окремо зберігаються власні клавіші старту та аварійної зупинки.
- Старі макроси сумісні з новою версією й автоматично отримують клавішу зупинки `F12`.

### Дизайн і реліз

- Додано літній дизайн лаунчера, окремі фони модулів та виправлені значки навігації.
- Світлу тему прибрано з інтерфейсу.
- Додано основний `CyberPW Assistant.exe` без чорного вікна PowerShell та з вбудованим логотипом CyberPW; переходи між модулями також працюють через нього.
- Оновлено portable-дистрибутив без зміни публічного URL релізу `v1.0.0`.
- Збережено актуальні посилання на [тему форуму](https://forum.cyberpw.fun/index.php?threads/titulhelper-1-0.271/) і [відеогайд](https://youtu.be/--JevuwyL7s).
## 1.0.0 — 2026-07-27

### TitulHelper

- Додано синхронізацію отриманих титулів без OCR: ID читаються напряму з підтримуваної збірки `ElementClient`.
- Додано перевірку розміру та SHA256 клієнта перед читанням; невідомі збірки безпечно відхиляються.
- Синхронізація працює лише на читання: запис у процес і зміна файлів гри відсутні.
- Повністю видалено OCR, його інсталятори, правила, звіти та налаштування.
- Для однакових назв у списку показується ланцюжок, щоб їх не плутати.
- Виправлено назву й відповідність титулу `Смітник`: `clientTitleId` змінено з помилкового `45964` на `1345`.
- Збережено ручний прогрес, відкриття списку титулів і введення координат мітки.

### Реліз і документація

- Оновлено версію лаунчера, portable-інструкцію, README та форумний гайд до 1.0.
- Додано відеогайд і прямі посилання на реліз 1.0.
- Macro Studio (клікер) і ГВГ залишено зі статусом **Beta**.
- Збірку очищено від локальних профілів, прогресу та макросів.
- Підтримуються Windows 7 SP1, Windows 10 і Windows 11 x64 з PowerShell 5.1.
## 0.90 Design Preview — 2026-07-26

### Нові модулі

- Додано `Macro Studio` (клікер) у статусі **Beta** — графічний конструктор сценаріїв клавіатури та миші.
- Додано екранну клавіатуру, паузи, текст, затискання клавіш, цикли, рух і кліки миші.
- Додано зчитування кольору пікселя та команду очікування кольору з допуском і тайм-аутом.
- Клавішу аварійної зупинки тепер можна призначити окремо для кожного макросу; старі сценарії автоматично використовують `F12`. Затиснуті клавіші відпускаються під час зупинки.
- Додано власний глобальний бінд запуску для кожного макросу; стандартна клавіша — `F10`, вибір зберігається у JSON.
- Додано карту територіальних війн із 51 точним полігоном, назвами, рівнями, нагородами та локальними даними боїв.

### Виправлення Macro Studio

- Замінено несумісний `SendKeys` для клавіатури на Windows virtual-key API.
- Виправлено помилку `A parameter cannot be found that matches parameter name 'ne0'`.
- Виправлено помилку `Keyword 'D5' is not valid` для цифрових клавіш.
- Перевірено 63 клавіші: цифри, `F1–F12`, Shift/Ctrl/Alt, стрілки, Enter, Tab і Space.
- Додано перевірку координат, HEX-кольору, допуску, тайм-ауту та кнопок миші до запуску сценарію.
- Формат макросів обмежено безпечними JSON-командами без виконання довільного PowerShell.

### Дизайн і сумісність

- Додано спільну дизайн-систему `CyberPW-Design.ps1` для всіх модулів.
- Округлено кнопки, картки, панелі, списки та таблиці.
- Додано DPI-масштабування, подвійне буферизування та системні кути DWM у Windows 11.
- Збережено сумісність із Windows 7 SP1, Windows 10 і Windows 11 на PowerShell 5.1.
- Перебудовано головну сітку на сім модулів і виправлено обрізані кнопки карток.
- Прибрано проблемні емодзі з критичних кнопок для коректного відображення у Windows 7.

### Карта ТВ / ГВГ — Beta

- Додано `gvg-map.png` і `territory-polygons.json`.
- Розділ ГВГ позначено як **Beta**, оскільки серверна синхронізація власників і боїв ще не реалізована.
- Додано точне визначення натиснутої території та підсвічування її межі.
- Додано власника, атакуючий і захисний клани, час бою та нотатки.
- `territories.json` винесено до локального користувацького стану та виключено з Git.

### Репозиторій і portable-збірка

- Оновлено `Build-Portable.ps1` для Macro Studio, карти ТВ, дизайн-системи та нових ресурсів.
- Додано чисту папку `macros/` до portable-збірки.
- Оновлено `.gitignore` для макросів, карти ТВ, теми та локальних даних.
- Повністю оновлено README, portable-інструкцію, таблицю сумісності, безпеку та список модулів.
- Перевірено всі зовнішні посилання: сайт, форум, кабінет, реєстрація, YouTube, Releases і підтримка відповідають HTTP 200.
